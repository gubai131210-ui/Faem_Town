# 后续计划

> 状态：方向已定（2026-11-13，决策 066）。M8 前两批做完了（决策 067、068）。M9 前两批做完了（水和天气，决策 069；光和烟，决策 070），后面两批还没有开工。各批里的具体名单（菜、新居民、异兽、新结局）都是提案，开画、写台词之前先给你过目。
> 相关文档：[设计文档](设计文档.md)、[架构](架构.md)、[进度](进度.md)、[决策记录](决策记录.md)。

## 1. 这份计划从哪来

三个来源：

1. **你提的事**。第一轮：主线不只一条、也可以不走主线；静态的图和资源动起来；人和动物按天气、时令有不同的行为；加过场动画。第二轮：加一条厨艺的方向；镇子要变样，多画东西，加居民、建筑、井以外的探险，结合中国传统神话做怪物和宠物；保留三个结局，再加新的结局。
2. **那篇对话**（ChatGPT 分享的“汇总游戏设计理念”，讲《星露谷物语》为什么好玩）。要点和对照在第 2 节。
3. **游戏现在的样子**：M0 到 M6 做完，M7 做了三批。从开局能玩到三个结局，但 M3 以后的内容大多还没有经过你试玩，数值全是第一版。

那篇对话最核心的一句是：

> 好玩的游戏不是让玩家一直有事做，而是让玩家不断产生自己想做的事，并且做了以后世界有看得见的变化。

拿这句话量现在的游戏，问题主要有三个：

- **想做的事只有一条路**。钓鱼、养殖、下井、升级工具全挂在七盏灯上，灯的顺序是定死的。
- **世界的回应大多是一句话**。点灯以后雾散开、货架多几样、居民说一段话，画面上的变化很少。结局是一张画加旁白。
- **世界自己的生活偏少**。居民只有平常和雨天两套日程，动作只有站、走、坐；四季换的主要是颜色。

## 2. 那篇对话的要点，和现在的差距

| 对话里的原则 | 意思 | 现在做到的 | 差在哪 | 放在哪做 |
|---|---|---|---|---|
| 核心循环 | 目标 → 自己选怎么做 → 得到反馈和资源 → 世界和能力变了 → 新目标 | 一天的循环、点灯的循环都有 | 奖励多数是“开下一道门”，很少是“多出几种选择” | M8、M12、M15 |
| 多个时间尺度 | 几秒、一天、几天、一季、几年都要有盼头 | 一天、节气、季、灯都有 | 几秒这一层的反馈弱；多年这一层只有结局 | M9、M12、M15 |
| 自由但有方向 | 给方向，不替玩家决定；任务可以不理 | 公告栏、第一天的提示 | 灯的顺序定死；第二天以后没有任何“接下来可以做什么”的地方 | M8 |
| 三层成长 | 数值成长最弱，能力成长改变玩法，世界成长带来归属感 | 工具升级、水渠、水牛犁地；雾散开 | 镇子在灯亮以后几乎没有变样 | M13 |
| 系统互相连接 | 每个系统至少和别的系统有两处联系 | 灯的供品把四种玩法串起来了 | 有几处是断头路，见 13.1。厨艺会把大部分接上 | M12、M16 |
| 有趣的限制 | 体力、时间、季节让选择有分量；不要永久错过 | 节日错过了明年再来 | 有三处会永久错过或没有对策，见 13.2 | M8、M16 |
| 世界有自己的生活 | 居民不是围着玩家转的功能按钮 | 日程、闲聊气泡、雨天换日程、节日 | 天气和季节对行为的影响少；动作少 | M10 |
| 奖励不过密，过程本身要有趣 | 别让最赚钱的做法是最无聊的做法 | 钓鱼和打斗有操作 | 没有算过各种玩法一天能挣多少 | M16 |
| 从体验反推机制 | 先说想让玩家感到什么，再定规则 | 设计文档是按内容写的 | 后面每个里程碑开头先写一句“想让玩家感到什么” | 每一批 |
| 先验证 30 分钟 | 头半小时不好玩，后面加多少内容都救不回来 | 第一天有提示 | 开局没有开场，头半小时没有专门看过 | M11 第一批 |
| 用试玩判断 | 五个问题，见第 14 节 | 每批都写了“待试玩” | 试玩积压了很多批 | 第 4 节 |

对话里还有一条要原样记住：**让玩家玩得久，和让玩家真的喜欢，不是一回事。** 所以这份计划里没有签到、每日任务、抽奖。成就有（你要的），但只记在册子里，不拿奖励催人。

## 5. M8：不止一条路

**想让玩家感到**：这是我的日子，先做什么、后做什么我说了算。

### 5.1 现在为什么只有一条路

| 想做的事 | 现在要先 |
|---|---|
| 钓鱼 | 点亮广场灯，老周才给鱼竿 |
| 盖鸡舍 | 点亮广场灯 |
| 养鸡鸭、盖蚕房 | 点亮河灯 |
| 养羊牛、养蜂 | 点亮牧野灯 |
| 下井 | 点亮井口灯 |
| 升级工具 | 下井挖到矿 |

### 5.2 把“地方”和“本事”分开

地方还是靠灯：雾抹掉了地方，点灯才回来，这是世界观的根，不动。本事改成靠人：和谁熟了，谁就教你、卖给你。

| 本事 | 现在 | 改成 |
|---|---|---|
| 鱼竿 | 广场灯 | 和老周熟到一定程度就给；灯亮了照旧直接给 |
| 鸡舍 | 广场灯 | 和青竹熟了就肯盖 |
| 鸡鸭、蚕房 | 河灯 | 和阿牧、青竹熟了就卖、就盖 |
| 钓具、饲料、稻草人上架 | 广场灯 | 跟着对应的本事走 |

井不拆：下井仍然要井口灯，工具升级仍然要井里的矿（你定的：有些东西就得下井拿）。

改完以后，一盏灯都不点的人在农场、镇上、南溪能种田、钓鱼、养鸡鸭、做菜、加工、过节、找回一部分人的忆。新地方、大牲口、井、好工具仍然要点灯。

这会改掉决策 041（鱼竿）、045 和 046（鸡舍、鸡鸭、蚕房）里“什么灯开什么”的几条。

### 5.3 灯的顺序放开，散雾能补成归名

- 广场灯以后，河灯、牧野灯、井口灯谁先谁后由玩家定。现在牛铃的线索要河灯（决策 048），井口的钥匙要牧野灯（决策 057），这两条去掉。东滩灯、山祠灯因为地理位置，顺序不变。
- 先点了灯、后来才把忆找全的人，能回井底把“散雾”补成“归名”。现在这是永久错过。

### 5.4 手账：一本可以不看的册子

名册面板再翻一页，不加新界面：

- 每条线一页（灯、人、家业、厨艺、山野），只写已经知道的事和下一步的线索。线索是居民说过的话，不是任务清单。
- 不弹窗、不标红点、没有完成度的百分比。
- 第一天的五步提示（决策 064）保留，睡过一晚以后说一次“想不起来做什么，翻翻手账”。

后面每加一条线，往手账里加一页。

### 5.5 委托不再做完就空

公告栏的八张做完以后，居民隔几天贴一张随手的小事（要几条鱼、几个蛋）。不限时，不做不罚。

### 5.6 分批

1. 本事从灯上拆下来；三盏灯顺序放开；散雾能补成归名。旧存档不受影响的测试先写。（完成，决策 067。稻草人仍跟广场灯，因为乌鸦那时候才来。）

## 6. M9：让画面动起来

**想让玩家感到**：这个地方是活的，站着不动也有东西可看。

### 6.1 现在哪些会动，哪些不会

| 东西 | 现在 |
|---|---|
| 树、草丛 | 会摇，幅度是固定的，不看天气 |
| 水面 | 有零星的波光，水本身不动 |
| 雨、雪、风、雾天的雾 | 整屏的效果会动；雨落在地上没有水花，下雨没有声音 |
| 挡路的雾团 | 不动，灯亮时淡出 |
| 作物、果树、花 | 不动 |
| 房子、灯、灯塔、古祠、摊子 | 不动；灯的光是恒定的 |
| 河灯、萤火虫 | 会动 |
| 居民 | 站、走、坐 |
| 动物 | 站、走、啄 |
| 对话头像 | 三个表情，各一张图 |
| 结局的画 | 一张图 |

### 6.2 做法

四种手段，从便宜到贵：

1. **着色器**：摇摆、水流、倒影、闪烁。不用新画图，树和草丛已经在用。
2. **代码画的多帧**：让画图函数多一个“第几帧”的参数，出两到四帧轮着放。
3. **粒子**：烟、落叶、花瓣、水花、尘土。`core/fx.gd` 已经有一个粒子的口子。
4. **Blender 的新动作**：人和动物的新姿势，最贵，放在 M10。

### 6.3 分批

**第一批：水和天气**（做完了，决策 069）

- 溪、河、海各有各的流向，水纹顺着流；海边有一道来回的浪线。
- 雨落在地面和水面上有水花；下得久了路上有水洼，雨停以后慢慢干。
- 树和草丛摇的幅度跟天气走：晴天轻，大风天大。
- 挡路的雾团缓缓翻动。
- 补下雨的声音、海浪的声音。

**第二批：光和烟**（做完了，决策 070）

- 石灯、灯笼、井灯的光轻轻跳动；灯塔亮了以后光柱转。
- 做饭的钟点茶馆和农舍的烟囱冒烟；铁匠铺开工时有火星。
- 傍晚窗户一家家亮起来，不是同时亮。
- 夏天晚上的水边有几只萤火虫。

**第三批：田里和树上**

- 作物有风的时候跟着晃；成熟的作物隔一会儿闪一下。
- 果树春天落花瓣，秋天落叶，冬天树枝上的雪偶尔掉一团；桂花林秋天飘桂花。
- 收获、敲开石头、锄地时弹出来的东西有落地的弹跳和一点尘土。

**第四批：界面和头像**

- 头像会眨眼，说话时嘴动。
- 物品进背包时图标飞向物品栏；钱数变化时数字滚动。
- 换季那天早上出门，屏幕上亮一下季节和节气的名字。

### 6.4 要注意的

- 渲染是 GL Compatibility，一屏能亮的灯有限（决策 061 碰到过）。闪烁只改亮度，不加新的灯。
- 384×216 的画面上，动得多了会乱。每一批先在一张地图上做，你看过再铺开。
- 我看不到动态。能做的是把每一帧拼成一条导出来检查画得对不对；动起来好不好看要你判断。

## 7. M10：天气和时令里的人与动物

**想让玩家感到**：今天和昨天不一样，是因为天变了，不是因为日历翻了一页。

### 7.1 现在有的

- 居民：平常和雨天两套日程；个别人有“灯亮以前”的一套。台词会看天气、季节、早晚。
- 动物：白天出来、天黑回去；下雨鸡不出来、鸭照常；雷雨和下雪都不出来。
- 节气规则：设计文档 4.1 有 24 条。代码里搜得到的有立春、惊蛰、春分、清明、谷雨、小暑、白露、霜降、大雪封山、小寒热食。**没搜到的**有小满涨水、夏至天黑推迟、处暑体力恢复、寒露蘑菇、立冬干草、大雪冰钓、冬至井下掉落、小寒体力消耗增加、小暑的树荫。它们有可能写在数据表里，开工前我先逐条核对。
- 雾天：设计文档说居民会忘记最近的对话、有专门的雾天台词。对话文件里只有六位写了雾天的话。

### 7.2 日程怎么扩

现在一位居民是整套整套地换日程。四季乘两种天气就是八套，写不动也测不动。

改成“平常日程 + 一串例外”：每条例外写条件（季节、节气、天气、钟点）和要换掉的那一段去处。加一条“夏天午后在树下乘凉”只写一行。算去处的函数现在是纯函数，改完还是，单元测试照旧好写。节日盖过一切的规矩不变。

### 7.3 居民的行为（提案）

| 条件 | 行为 |
|---|---|
| 下雨 | 在外面走的人打伞；小满踩水洼；老周照样在码头，披蓑衣 |
| 雷雨 | 路上没有人，都在屋檐下；姜婆婆收晒着的药 |
| 雾 | 走得慢，出门晚；白鹭专挑这天出来画；柏先生不出门 |
| 大风 | 阿禾收摊早；云娘追被吹跑的幌子 |
| 雪 | 青竹扫门前的雪；小满堆雪人，广场上留一个到化雪 |
| 小暑、大暑 | 中午都在阴凉处，摇扇子；石叔改成早晚打铁 |
| 冬天 | 出门晚、回家早；站着的时候搓手、呵白气；茶馆门口人多 |
| 春天 | 阿禾在门口晒种子；陆远上山采药，白天不在镇上 |
| 秋天 | 各家门口晒东西；阿牧赶着牲口从镇上过一次 |
| 节日前一天 | 相关的人在场地上搭东西 |

新动作（Blender，居民共用一套骨架）：打伞走、扇扇子、搓手、扫地、蹲下。老周持竿、白鹭画画、石叔打铁这三个干活的姿势一起做。

### 7.4 动物的行为

| 条件 | 行为 |
|---|---|
| 小暑、大暑的中午 | 往树荫下走，趴着；在树荫下心情涨一点 |
| 下雨 | 鸭扑水；羊和牛挤到棚檐下 |
| 冷天 | 挤成一堆；出来得晚 |
| 大风 | 鸡贴着墙根 |
| 雾 | 牛羊往一个方向看（呼应阿牧说的“总往雾里走”），不真的走丢 |
| 猫 | 雨天不出来；晴天下午在出货箱上晒太阳 |
| 狗 | 下雪天在雪地里打滚；雾天坐在门口朝外看 |

新动作：趴下、抖水。禽类和四条腿各做一套。

### 7.5 只当风景的小东西

春天屋檐下的燕子，夏天水边的蜻蜓和树上的蝉声，秋天天上飞过的雁，冬天雪地上的麻雀。不能抓、不进背包，只是画面和声音。

### 7.6 分批

1. 核对节气规则，补上该有的；日程改成“平常 + 例外”，行为不变，测试全过。
2. 五个新动作和三个干活的姿势；下雨和下雪的行为。
3. 夏天和冬天的行为；动物的行为。（完成，决策 075。做了摇扇、早晚打铁、冬天晚出早归、搓手呵气、茶馆门口、立冬干草进舍、大雪银鱼、暑天心情 +8。趴下、抖水、挤成一堆、猫狗仍是提案。）
4. 雾天和大风；风景里的小东西；每人补雾天的话。（完成，决策 077。雾天晚出门、走得慢、柏先生不出门、白鹭画画、今天再说仍是当天的话；大风阿禾早收摊、云娘追幌子；燕子蜻蜓雁麻雀和夏天蝉声。雷雨屋檐、动物趴下抖水、猫狗仍是提案。）

## 8. M11：过场动画

**想让玩家感到**：重要的事是看见的，不是被告知的。

### 8.1 现在有的

- 地图有两个钩子：`entered()` 和 `cutscene`。小满带路、老周认灯这两段靠它们做：人走过来，面对面说话。
- 点灯：停一下、震屏、提示条、一段旁白。
- 结局：黑屏、一张画、旁白、结局的名字。
- 没有开场。没有制作人员名单。

决策 039 说“不另起过场系统”，决策 060 说“不做过场动画”。这一个里程碑推翻这两条。

### 8.2 做法：一个小的过场播放器

过场写成一串步骤，由播放器按顺序执行。步骤的种类：

- 镜头：移到某处、跟着某人、拉近拉远、上下加黑边
- 人：走到某格、转身、做一个动作、头顶冒一个表情气泡、淡入淡出
- 画面：整屏变色、换天气、放一张全屏的画、屏幕上出一行字
- 声音：放一个音效、换音乐、静音
- 对话：播对话文件里的一段，等它说完
- 等待

规矩：

- 每段过场都能跳过。
- 过场只是演出，不改游戏状态。状态在过场开始前或结束后由原来的代码改，这样跳过和不跳过结果一样，也好测。
- 放在 `game/`，因为它要同时碰镜头、地图、玩家和对话框。
- 看过的过场记下来，能在手账里重看。

### 8.3 要做的过场

| 批 | 过场 | 现在是什么 |
|---|---|---|
| 一 | 播放器本身；**开场**：城里的一张桌子、信和钥匙、车窗外的雾、到农舍门口 | 没有，直接站在屋里 |
| 一 | **七盏灯点亮**：镜头升起来，雾从灯往外退，露出后面的地方，再落回玩家 | 震屏加旁白 |
| 二 | 姜婆婆认出相片；雾里的白鹿；柏先生坦白；老秦交钥匙 | 站着说话 |
| 二 | 头一回下井；四个首领登场 | 一句提示 |
| 三 | **三个结局**：每个结局三到四张画，画里有人走动；散雾的葬礼、归名的镇民下井真的演出来；最后是制作人员名单 | 一张画 |
| 四 | 每位居民的五级忆：画面褪成旧照片的颜色，演一小段当年的事 | 一段话 |
| 四 | 节日开场；除夕守岁到新年的那一刻 | 一句提示 |

第四批的忆有十一位，量大。先做一位给你看，再决定其余的做多细。后面的厨艺、镇子、山野、新结局各自的过场，在各自的里程碑里做，都用这个播放器。

## 9. M12：厨艺

**想让玩家感到**：我想把这一桌菜凑齐。为了这一口，值得等到那个节气、跑那一趟。

### 9.1 现在有的

农舍的灶台，十几道菜：开局会五道，云娘教七道，三位居民的忆各带一道。吃了回体力，两种效果（走得快、干活省力）。做菜没有过程，按一下就得到。菜只能自己吃或卖。

### 9.2 食单：约 72 道

按两个办法排，一道菜两边都算：

**按席面分六类**：冷盘、热菜、汤羹、主食、点心、茶酒。

**按来历分四组**：

| 组 | 多少 | 是什么 | 举例 |
|---|---|---|---|
| 节气菜 | 24 | 每个节气一道，只有那几天做才是“当令” | 立春春卷、清明青团、谷雨香椿拌豆腐、立夏乌米饭、夏至凉面、立秋红烧肉、秋分桂花糕、冬至饺子、小寒腊八粥、大寒八宝饭 |
| 家常菜 | 约 24 | 镇上人家的菜，各地都有的 | 番茄炒蛋、红烧鱼、腌笃鲜、荷叶鸡、葱油饼、酒酿圆子 |
| 人家的菜 | 约 12 | 每位居民一道，和他的忆连着 | 现有的送行面、草药茶、雾露；老周儿子爱吃的那一碗，云娘哼着歌做的那一道 |
| 难得的菜 | 约 12 | 材料难凑，做出来是一件事 | 用传说鱼的、用巨型瓜的、用井底东西的、用山野里异兽给的东西的 |

现有的菜全部留着，id 不动，归进这四组。

我的建议是以江南的菜为底（和白墙黛瓦、茶、稻、藕是一个地方），再放一部分别处的名菜进“难得的菜”，由货郎带来做法。具体的 72 道我列成一张表给你过目以后再画。名单过过了，十六道新的已经进菜谱（决策 138）。上面举例里的青团、红烧肉、香椿没有做。

### 9.3 做法从哪来

- 云娘教（现有）；茶馆里吃过一回，她才肯教。
- 居民的忆（现有）；熟了以后去人家里，看见灶上在做什么。
- 节日上吃到的。
- 残页：井里、雾天、山野里捡到半张菜谱，凑齐两半才看得懂。
- 自己试：灶台上多一个“随手试试”，放三样材料进去，对了就学会，不对得一碗“说不上来的东西”。给不想查表的人一条路。
- 货郎（M13 的新居民）每个节气带来一道外地的做法。

### 9.4 时令怎么起作用

- **当令**：节气菜在自己的节气里做，品质高一档，效果翻倍。别的日子也能做，只是普通。
- **新鲜**：当季的作物、当天的鱼和蛋做出来更好。放过季的不扣，只是没有加成。这样不逼人，但让“今天钓到的鱼今天吃”有意思。
- **只有那时候有的材料**：香椿只在谷雨前后长，桂花只在秋天，蟹只在夏秋，冰下的银鱼只在大雪以后。错过了明年再来，不会永久错过。
- 天气只管一件事：下雨和下雪天，热汤热食的效果长一些。

### 9.5 难找的材料

材料尽量从已有的东西里来，把断头路接上：

- 已有但现在没用处的：鱼（26 种，现在不能做菜）、花、蜂蜜、奶酪、腌菜、茶叶、巨型瓜、三条传说鱼、蟹笼里的虾蟹。
- 设计文档里写了还没做的：冬菇和菌房、忆昙（只在夜里开一次）、冰钓的银鱼。
- 要新加的，约 20 样：调料（酱、醋、酒、糖，由新的加工设备酱缸和酒坛出）、糯米、香椿、桂花、几样山野里才有的菌子和野味、井里的岩盐、海上的几样。

每一样难找的东西只在一处、一个时候有，手账里写线索，不写坐标。

### 9.6 做菜的动画

分两层，这样 72 道菜不用画 72 套过程：

- **过程**：八种做法各一段，切、炒、蒸、炖、炸、煮、拌、烤。主角在灶前的动作（Blender 新动作）加锅里的画面（火、油花、蒸汽）。可以按键跳过。
- **成品**：每道菜自己的一张大图（48×48 左右），带两到四帧的动静：热气、油光、汤面晃、糖丝拉开。出锅时放大亮出来，写上名字；当令的多一圈光。

头一回做成一道菜是完整的一段；以后再做只放一秒的短版，免得烦。

### 9.7 饭桌

农舍里加一张八仙桌：

- 做好的菜能摆到桌上。每道菜有一张桌面上的小图（盘、碗、蒸笼、砂锅各有样子），摆上去看得出是什么。桌子一共八个位。
- 凑成一席（比如两冷四热一汤一主食）有席面的名字；全是当令的、全是一位居民爱吃的，各有说法。
- **请客**：请一到三位居民来吃。他们坐到桌边，吃到爱吃的各有反应，加熟悉度，有的会说起平时不说的事。这是人线的另一条路。
- 饺子宴、除夕的长桌改用同一套摆法，你带去的菜真的摆在桌上。
- 茶馆做成能进的屋子以后（M13），里面也有桌子，云娘的菜牌上会挂你教给她的菜。

### 9.8 成就

- **食单**（手账里的一页）：72 格，做过的亮，没做过的是剪影，只提示是哪一类、大概哪个时候。
- **称号**，云娘当面给：帮厨、掌勺、大师傅，再往上一个留给收尾。条件是做过多少道、当令做过多少道、请过多少桌。
- **成套的**：二十四节气菜做全、每位居民的那道做全、一桌八道全是优品。做成了在农舍墙上挂一样东西，镇上的人会提起。
- 不弹大窗，只在左上角出一条提示。

### 9.9 别让它变成刷钱

对话里专门提过：开发者不让“每样食材做成菜都更赚钱”。所以菜的卖价不高于材料的总价太多；菜的价值在吃、在请客、在席面，不在卖。M16 的收入模拟里会专门看这一条。

菜的效果从两种加到六种左右（多出回生命、灯油省、鱼来得快、心情好）。同时只有一种的规矩不变。

### 9.10 分批

1. 食单的表（72 道的名字、材料、做法、时令）给你过目；鱼和花能做菜；当令和新鲜的规则；食单页。
2. 八种做法的过程动画；先画 24 道家常菜的成品图。
3. 饭桌、摆盘、席面；请客。
4. 24 道节气菜；只有那时候有的材料；菌房、忆昙、冰钓。
5. 调料和两台新设备；残页、自己试。
6. 人家的菜、难得的菜（一部分要等 M13、M14 的货郎和山野）；称号和成套的成就；节日长桌换新摆法。

## 10. M13：镇子变样、新居民、能进的屋子

### 10.1 每盏灯带回来什么（提案）

## 11. M14：山野和神话

**想让玩家感到**：山里还有我没见过的东西，而且不是每一样都要打。

### 11.1 怎么放进这个故事里

雾抹掉的不只是镇子，还有山里的传说：人不记得了，它们也就没了形。灯一盏盏亮起来，人想起来的不只是亲人，还有小时候听过的那些东西。井里被忘掉的物件变成“忘形”；山野里被忘掉的传说，回来的时候是“异兽”。岚本来就是这里头的一位。

这样神话是从“忘和记”里长出来的，不是另贴上去的一层。说书人每讲一段，手账的“山海录”里多一条线索。

### 11.2 三处新的野外

和井不一样：井是随机的、一层层往下、主要是打。野外是手摆的地图，看的是**什么时候去**。

| 地方 | 怎么去 | 样子 | 特点 |
|---|---|---|---|
| 竹海 | 河埠过桥 | 竹林、溪涧、石径 | 夜里和雾天是两个样子；有岔路和要记的路标 |
| 后山 | 山祠再往上 | 山路、瀑布、崖洞、山顶 | 不同节气开不同的路：冬天溪水冻了能过，夏天涨水过不去 |
| 雾岛 | 东滩坐船娘的船 | 海上的小岛、礁石、潮洞 | 潮水涨落决定哪里走得通 |

每处都有只在那儿长的食材（接 M12）、几只异兽、一些要找的东西。武器和翻滚现在只在井里能用，放开到这三处。

### 11.3 异兽：约 16 种（提案，名单要你过目）

取自《山海经》和民间的传说，分三类。

**要打的（凶）**，四五种，是野外的首领：

| 异兽 | 出处里的样子 | 在游戏里 |
|---|---|---|
| 年 | 除夕出来，怕响、怕红、怕火 | 除夕夜闯到镇口，全镇用灯笼和爆竹赶；亮的灯越多越好赶 |
| 夔 | 一只脚，出入必有风雨，声如雷 | 后山，只在雷雨天出来 |
| 山魈 | 山里的独脚怪 | 竹海夜里，学人说话把你引进岔路 |
| 饕餮 | 贪吃，什么都吞 | 不是打倒，是喂饱：要端上一整桌它没吃过的菜（接 M12） |

**要想办法的（中）**，五六种：不打，要看懂它要什么。

| 异兽 | 出处里的样子 | 在游戏里 |
|---|---|---|
| 狌狌 | 像猿，好酒，知道过去的事 | 拿酒引它出来；它说得出一段没人记得的往事 |
| 白泽 | 能说话，通万物之情 | 后山顶上；见过它以后，山海录里写明每种异兽的忌讳 |
| 精卫 | 衔木石填海的鸟 | 东滩和雾岛之间来回飞；帮它一回，退潮的时间长一些 |
| 鲛人 | 水里的人，哭出来的是珠 | 雾岛的潮洞；拿东西换珠 |
| 毕方 | 一只脚的火鸟 | 后山，旱天出现；引它点着崖洞里的灯 |
| 灶君 | 灶王爷，腊月上天说人家的好坏 | 小寒那几天祭灶；祭了以后一年里试菜更容易试对 |

**能结缘的（祥）**，六种，是宠物：

| 异兽 | 出处里的样子 | 结缘以后 |
|---|---|---|
| 腓腓 | 像狸，白尾巴，养了可以忘忧 | 摸它一下，当天晕倒过的损失减半；最贴这个故事的一只 |
| 当康 | 像小猪，叫声是自己的名字，出现就是丰年 | 它在的那天，收成多一点 |
| 文鳐 | 会飞的鱼，夜里飞，见了天下大熟 | 养在池塘里；夜里有时飞起来 |
| 乘黄 | 像狐，背上有角 | 跟着你走，走得快一些 |
| 耳鼠 | 像鼠，用尾巴飞 | 在山野里替你找到藏着的东西 |
| 玉兔 | 月亮上捣药的兔子 | 月圆的晚上在后山；捣出来的药给药铺 |

当康、文鳐、乘黄、玉兔这四只的效果已经接上（决策 139）：当天多收一个、逢三的夜里飞过农场池塘、只在竹海白天跟着、药铺喝一剂。结缘仍只有腓腓和耳鼠，这四只不跟回家。

结缘的办法各不一样：喂它爱吃的菜、在对的节气和天气去、帮它一件事。结了缘的住在农场，同时带一只出门。原来的猫狗不变。

异兽的画法：个头小的用代码画（和井里的忘形一样），要走要跑的宠物用 Blender 的动物骨架。

### 11.4 山海录

手账里的一页：听说过的是一句话，见过的有画，结过缘或打过的写全。和鱼谱、食单是一个做法。

### 11.5 分批

1. 竹海地图；武器在野外能用；山魈、狌狌、乘黄；山海录。
2. 后山地图和按节气开合的路；夔、白泽、毕方、玉兔、当康。
3. 雾岛地图和潮水；精卫、鲛人、文鳐。
4. 年（除夕）、灶君（小寒）、饕餮；腓腓、耳鼠；结缘和带宠物出门。

这一个里程碑的量和 M5 整个矿井差不多。

## 12. M15：几条线的收束和新结局

**想让玩家感到**：我过的这种日子，有它自己的结果。

### 12.1 原来的三个结局

留雾、散雾、归名都保留，条件不变（除了散雾能补成归名）。M11 第三批把它们演出来。

加一本**结局簿**（手账的一页）：看过的结局记下来，能重看；没看过的只有一个名字的影子。

### 12.2 另外几条线

**人线**。十一位居民各五段忆，现在已经有，但只是灯线的配角：

- 忆簿按时间排满某一段（“出事前一年”“那天早上”“之后三天”），各有一个小结，由柏先生或小满说出来。
- 每位居民忆满以后有自己的结尾：一段过场，加上镇上一处看得见的变化（阿禾换回老招牌、青竹的桥、云娘把歌唱完）。
- 名单和全家福拿给别的居民看，各有反应；矿工巷的屋子和名单上的名字对得上。

**家业线**。把农场从荒地过成家业：

- 六个行当，各认一位师傅：种田（阿禾）、钓鱼（老周）、养殖（阿牧）、打铁和下井（石叔、老秦）、采集（姜婆婆）、灶台（云娘，就是 M12 的称号）。
- 每个行当三级，条件用已有的记录算：鱼谱钓到几种、养过几种动物、出过几种优品作物、下到第几层。师傅当面说一句，除夕柏先生念账时一起提。
- 每级的奖励是镇上或农场的一处变化，加一个小便利，不给钱。

### 12.3 新结局：三个（提案）

井一定要下：下面每一个都要用到井里才有的东西，但不要求先点最初的灯。它们和原来三个不冲突，一局里可以都看到。

| 结局 | 条件 | 是什么 |
|---|---|---|
| 团圆饭 | 厨艺到头：节气菜做全，每位居民的那道做全 | 除夕在广场摆二十八副碗筷的长桌。多出来的那些位子是给谁的，全镇的人慢慢想起来。厨艺线的收尾，也从另一头碰到那一天 |
| 山海有名 | 山野到头：十六种异兽都见过，六只都结了缘 | 白泽把山里每一样东西的名字念一遍。念到最后一个，是一头白鹿 |
| 家业 | 六个行当都到三级 | 镇上给农场挂匾。信箱里来一封信，是城里的人问：听说那儿有个镇子，还能去吗。镇子回到了地图上 |

每个结局照 M11 的做法演：几张画、有人走动、旁白、结局的名字，之后接着玩。

还有一个我想到但拿不准的，**要你定**：姜婆婆留着的那半张船票，另外半张在哪。可以做成第七个结局“远行”（主角带着婆婆坐船去找母亲），但它要写主角的母亲现在怎么样了，这是设计文档里一直没写的事。

### 12.4 分批

1. 结局簿；人线的时间段小结和十一位的结尾。
2. 家业线：六个行当的条件、师傅的话、奖励。
3. 三个新结局。

## 13. M16：把断头路接上，算账，收尾

### 13.1 断头路

厨艺做完以后大部分已经接上。剩下的：

| 东西 | 现在 | 接上 |
|---|---|---|
| 鱼、花 | 不能送礼 | 能送礼 |
| 井里的九件遗物 | 只是收藏 | 拿给老秦或白鹭看，各有一句话 |
| 居民之间 | 闲聊只有气泡，没有话 | 走近了能听见一两句，按两人的关系写 |

### 13.2 永久错过和没有对策的地方

- 先点灯就拿不到归名：M8 第一批改。
- 霜降冻死作物，除了提前收没有办法：加一个办法（稻草盖一格地）。
- 铁锹一下挖掉果树，没有确认：加确认。
- **游戏速度**：设置里能把一天调慢。对话里提到有玩家被时钟逼得焦虑，这个办法最便宜。

### 13.3 算账

写一个不开窗口的脚本，模拟“只种田”“只钓鱼”“只养殖”“只下井”“只做菜”“混着来”几种过法，各跑一年，输出每天能挣多少、体力花在哪。这个我自己能跑、能看结果。目的是确认：

- 没有一种过法比别的高出一大截。
- 最挣钱的做法不是最无聊的做法。
- 做菜不是“什么材料做成菜都更赚”。

然后统一调价钱。

### 13.4 其余

- 性能：进地图画地面已量过并改过（决策 117）。数值平衡还没做。动的东西再多以后可以再量一次。
- 收音机的人声（决策 016）：公开发布前要换。
- 音乐：新地方（竹海、后山、雾岛、室内）各要一首。仍是代码合成，好不好听要你听。
- 导出成独立的游戏，跑一遍。

## 14. 每一批怎么算做完

沿用 `AGENTS.md` 的规矩：单元测试过、无窗口流程过、带窗口跑一次看截图、更新进度。另外加两条：

- 每一批开头写一句“想让玩家感到什么”，做完对着它看。
- 试玩时记下对话里的五个问题：
  1. 没有提示的时候，你能不能说出下一件想做的事？
  2. 玩了二十分钟，你说得出自己或者这个地方有什么变化吗？
  3. 你有没有试不同的玩法，还是只重复最挣钱的那一样？
  4. 你有没有对哪个人、哪个地方、后面的事好奇？
  5. 关游戏的时候，是心满意足，还是怕错过什么不敢关？

动态、手感、声音、过场的节奏，我都判断不了，全靠你试玩。

## 15. 顺序、理由和风险

| 顺序 | 里程碑 | 理由 |
|---|---|---|
| 0 | M7 收尾 | 试玩积压和丢按键的流程不解决，后面看不准 |
| 1 | M8 不止一条路 | 你已经定了；改动小，改完马上是另一种玩法；手账是后面每条线的落脚处 |
| 2 | M9 动起来 | 最独立，不碰规则；做菜的动画、过场都用得上这些手段 |
| 3 | M10 天气和时令 | 要新动作；日程的改法要先稳下来，新居民直接用新的写法 |
| 4 | M11 过场 | 后面每个里程碑都要它 |
| 5 | M12 厨艺 | 前五批不依赖新地图，可以先做；最后一批等 M13、M14 |
| 6 | M13 镇子变样 | 新居民和室内是 M14 的入口 |
| 7 | M14 山野和神话 | 量最大，依赖前面全部 |
| 8 | M15 收束和新结局 | 要等各条线的内容齐了 |
| 9 | M16 收尾 | 算账要等规则不再变 |

如果你最想先看到厨艺，可以把 M12 的前三批（食单、做菜动画、饭桌）提到 M9 后面，它们只用到灶台和农舍。

风险：

| 风险 | 应对 |
|---|---|
| 量很大，大约是已做完的量再做一遍 | 每批做完都能玩；每个里程碑的名单先过目再做；数字随时可以砍 |
| 前面的内容还没试玩过就往上加 | M7 收尾排在最前；每个新里程碑的第一批做完请你玩一次再往下 |
| 新内容和旧存档 | 新居民不进归名的条件；旧的 id 一个不改；每批先写旧存档的测试 |
| 神话和原来的故事不搭 | 用“被忘掉的传说”这一个说法接进去（11.1）；名单和每只异兽在故事里的位置先给你看 |
| 72 道菜的图 | 过程只画八种做法；成品图先画 24 道看效果 |
| 我看不到动画、听不到声音 | 帧条导出自查；其余靠你试玩 |
